

## 一、功能清单

### 🔴 MVP 必须（第一周就做）
| 功能 | 理由 |
|---|---|
| 商贷计算（等额本息/本金） | 核心功能，满足主搜索意图 |
| 公积金贷款计算 | 首购年轻人高频需求 |
| 组合贷计算（商贷+公积金混合） | 差异化亮点，很多竞品没有 |
| 月供/总利息/还款总额结果展示 | 计算器的基本输出 |
| 首年逐月还款明细表 | 增强可信度，用户会截图保存 |
| 移动端适配 | 目标人群 80%+ 用手机搜索 |
| SEO 文字内容区 + 免费声明 | 收录与合规的底线 |

### 🟡 第二期（有流量后再做）
- 提前还款计算器（省息对比）——搜索量大的独立长尾词，值得单独一页
- LPR vs 固定利率对比
- 不同年限/利率方案对比表（30 年 vs 20 年）
- 房贷利率查询页（各城市最新 LPR）
- 结果页分享/保存图片功能（带来社交传播）

### ⚪ 可不做
- 用户注册/登录（MVP 阶段纯属劝退）
- 评论区（无流量时只会显得冷清）
- App、小程序（网站没跑通前都是浪费）

## 二、首页信息结构

```
首页
├── 顶部：Logo + 标语（"3 秒算清你的月供"）
├── 计算器卡片（首屏核心，进页即用，不折叠）
├── 计算结果区（含明细表）
├── 工具内链区：公积金计算器 | 提前还款计算器 | 利率对比
├── 图文内容区：
│   ├── 房贷计算器怎么用
│   ├── 等额本息 vs 等额本金怎么选
│   ├── 2026 首套房贷利率一览
│   └── 首次购房贷款流程 5 步走
├── 常见问题 FAQ（配 FAQ 结构化数据）
└── 页脚：免责声明 · 隐私政策 · 备案号
```

## 三、用户使用流程

1. 用户在搜索引擎搜「房贷计算器」→ 点进首页
2. 首屏直接看到计算器，无需任何点击，默认填好常用值（100 万/30 年/当前 LPR）
3. 改成自己的数字 → 点「开始计算」→ 立刻看到月供和总利息
4. 切换还款方式对比差异 → 看明细表
5. 往下滚动读 FAQ / 点内链工具继续算（增加停留时长和 PV）
6. 收藏网站或返回搜索结果——页面体验好 → 排名逐步上升
